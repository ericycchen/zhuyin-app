💡 版本差異與說明

注音小幫手提供三種核心版本，適應不同的使用場景：

⚡️ 高速版 (pinyin-pro)

優點：完全在本機（瀏覽器端）執行，無任何網路延遲，即時轉換。效能極致、流暢度最高。

缺點：在少數罕見的破音字或古文詞彙中，可能無法百分之百精確判斷語境。

📖 萌典版 (教育部國語辭典)

優點：串接教育部官方國語辭典，破音字、成語及古語判斷最精準權威。

缺點：每次輸入皆需發送網路 API 請求，容易受網路品質影響產生微幅延遲。

🔍 比對版 (推薦使用)

完美結合：融合「高速版」的流暢與「萌典版」的權威！

  • 輸入文字後，高速版會在一瞬間完成注音渲染（0 延遲，保證無卡頓）。
  • 隨後在背景非同步查詢萌典權威資料庫。
  • 若發現萌典注音與高速版有差異，系統會自動將該字標註為橘色，並預設採用權威的萌典注音。
  • 滑鼠懸停（或手機點擊）該字時，會浮現提示顯示原高速版的注音，方便進行快速比對與學習。
